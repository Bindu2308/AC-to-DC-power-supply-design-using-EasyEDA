# AC-to-DC-power-supply-design-using-EasyEDA

# Overview

This project is a compact AC to DC power supply PCB designed to convert mains AC input into a regulated low-voltage DC output. The board is intended for basic electronics projects that require a stable DC supply from an AC source.

The PCB is designed using EasyEDA Standard with a focus on simplicity and manufacturability.

# Features 
- AC input via screw terminal
- Bridge rectifier for AC to DC conversion
- Filtering capacitors for ripple reduction
- Linear voltage regulation
- LED indicator for power status
- GND copper pour for improved grounding
- Mounting holes for enclosure support

# Components Used 
- Bridge Rectifier (D1)
- Transformer / AC Input (T1)
- Linear Regulator (U1)
- Electrolytic Capacitors (C1, C2)
- Resistor for LED (R1)
- Power LED (LED1)
- Screw Terminals (P1, P2)

# PCB Design Details
- Designed in EasyEDA Std
- Single-layer PCB
- GND copper pour with thermal relief
- DRC-compliant clearance rules
- Silkscreen labels for easy assembly
- Separate AC input and DC output sections
